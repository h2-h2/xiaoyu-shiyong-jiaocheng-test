##实测结论：**这页没给你"建"的口子，所以不是你不会用。**

——进【数据库】页看到的是一张空表：**"数据库列表（共 0 个）"**、下面"暂无数据"。
——页面上**只有三个按钮：搜索 / 筛选 / 排序**。
——**翻遍整页没有"新建数据库"入口。**


##列表字段是有的（说明功能是"留着"的，就是没开给你）

数据库名称 / 数据库类型 / 数据表数量 / **智能体引用数** / 创建者 / 状态 / 更新时间

——注意"**智能体引用数**"这一列 —— 说明它的设计用途是：**建好的库被智能体引用**。
——但建库这步，页面上没给你。大概率是**平台侧/管理员才能开**（要建就去找管理员问）。


##那"要用数据"怎么办（替代方案）

| 场景 | 走法 |
| 小规模、要 AI 会答 | **当知识库喂**：知识库里用【问答】知识类型，一问一答最准 |
| 文档/表格类 | 知识库【文件】类型，Excel 走【Excel 表格解析】 |
| 结构化数据、要真算 | **交超级Agent** —— 它有 bash，能直接处理 CSV/JSON |
| 要平台级联查 | 等管理员开数据库，或走【工作流】里的 MCP插件 |

---
**记住：数据库这页现在就是个"空壳列表"，别在这儿耗时间。要数据能力，知识库 + 超级Agent 先顶上。**
