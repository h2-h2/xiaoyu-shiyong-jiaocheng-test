##这个文件讲【分段内容怎么看】——解析完成后才能看

——前提：文件【解析进度】显示"已完成"。

##能干什么

1. **看分段内容**：点进文件，按切片一条条看 AI 实际"读到"的内容。
2. **搜片段**：输入关键词，在此文件内搜索相关片段——这是**验"能不能被捞出来"最细的一级**（整库级的验法看《做完后一定要做召回测试》）。
3. **切 markdown 预览**：切换预览格式。
4. **对比版本**：文件被**上传过新版本**、或**修改过片段内容**时，切到 markdown 预览可以**切到备份版本**，对比不同版本的差异。

##跟召回测试的分工

| 你想验什么 | 去哪 |
| 某条片段内容对不对、有没有被切碎 | 文件分段里看 / 搜 |
| 一个问题能不能命中这个库 | 【工具】→【召回测试】 |
| 命中之后回答得好不好 | 挂智能体对话，或先用《立即问答》粗验 |

---
**记住：【分段】列是 `-` 或解析没完成的文件，点进去也没片段可看——先回【解析策略】查解析。**
