##进去【解析策略】之后，是三个页签，别只看一个就出来

——位置：知识库详情 → 左侧【设置】→【解析策略】

| 页签 |--|基本信息|
知识库名称（可【编辑基本信息】）/ 描述 / 创建人（可【移交】）
创建时间 / 更新时间
**文件总数 / 解析成功数 / 解析失败数 / 解析进度**（这几个是你排查问题的第一现场）
**【一键重新解析】** ← 解析卡住/失败，先按这个
**空间使用**（`27.06KB / 100GB`）
**总字数**（显示"约11163字"）
**关联助手（1）** ← 引用这个库的智能体，点【前往助手广场】能跳过去

| 页签 |--|模型配置|
**向量模型**：bge-m3-tei / bge-m3
**文本生成模型**：Qwen3.8-Flash-Next / qwen3.8
**图像解读模型**：Qwen3.8 / qwen3.8
——下面两个按钮：**【重 置】/【保 存】**

| 页签 |--|默认解析策略|
就是【文件】那篇讲的：解析设置（文档解析 / Excel / 图片 / 音视频）+ 智能摘要 + 元数据索引 + 分段设置。
——**这是"这个库以后新传的文件默认怎么解析"**。

##排查顺序（三页签的正确用法）

1. 先看**基本信息**的【解析进度】和【解析失败数】→ 不是 100% 就先【一键重新解析】
2. 再看**模型配置**里【向量模型】有没有配
3. 最后去【工具】→【召回测试】验能不能捞出来
4. 参数想改 → 改**默认解析策略**，但注意：**已解析的老文件不会自动变**，要重新解析。

##官方手册补充（2026-10-15）

——【基本信息】里两个数的口径，手册写得更死：
**空间使用情况**：可由**资源库管理员扩容**（普通成员改不了配额，要加容量找管理员）。
**知识库总字数**：是对**本库内所有文档深度分析提取出来的文字总数**——不是文件本身的字节数，是 AI 真正读到的字数。
